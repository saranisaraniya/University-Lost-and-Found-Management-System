UNIFIND – University Lost and Found System

1. Introduction

UNIFIND is a web-based University Lost and Found Management System. It helps students, lecturers, and staff report lost and found items easily.

2. Objectives

- To report lost items.
- To report found items.
- To search for lost and found items.
- To submit item claims.
- To manage reports through an admin panel.

3. Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

4. Main Users

- Students
- Lecturers
- University Staff
- Admin

5. Main Features

- User Registration and Login
- Report Lost Items
- Report Found Items
- Search Items
- Claim Items
- Admin Dashboard
- Edit Profile
